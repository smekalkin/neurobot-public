- Разрешены чтение и изменение данных в пределах прав ключа. Перед любым запросом, который создаёт, меняет или удаляет данные (POST, PUT, PATCH, DELETE), скажи человеку в этом чате, что именно собираешься сделать, и дождись подтверждения.
- Не удаляй ничего без прямой просьбы. Массовые изменения — только по явной просьбе и сначала на одном объекте. Сначала прочитай объект, потом меняй; записывай только проверенные факты.
